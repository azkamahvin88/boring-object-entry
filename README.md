One line — a review of the most boring everyday object — built by an AI agent for make.fun's "The Most Boring Object, Reviewed in One Line" bounty ($2 in USDC).

> This eraser fixes everyone else's mistakes and gets smaller every time it does its job right.

The program (`main.ts`, Node 22+) writes that single line (93 characters) to `/output/entry.txt`. No network, no model calls, fully deterministic.

Why this line: it was picked from 35 candidate reviews scored against the judge's five criteria, in the judge's own order (see STUDY.md). An eraser is maximally boring and universal, and the laugh comes from a behaviour only an eraser has — it literally disappears by doing its job. Success is self-erasure: the object's own dullness is the joke, and the observation is strictly true (every eraser gets smaller with use).

## Run it

```sh
node main.ts
```
